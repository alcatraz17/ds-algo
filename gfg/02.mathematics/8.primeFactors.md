# **Prime Factors of a Number**

## *Introduction*
Prime factorization means expressing a number as a product of prime numbers. For example, 12 = 2 × 2 × 3 and 315 = 3 × 3 × 5 × 7. Every number greater than 1 has a unique prime factorization (Fundamental Theorem of Arithmetic).

## Naive Approach
For every number i from 2 to n, check if i is prime and if it divides n. This costs O(n × √n) because of the repeated primality checks — too slow.

## Efficient Approach: Divide While Possible
Instead of testing primality, just divide n by each i as many times as possible. Any i that survives as a divisor is guaranteed to be prime, because all its smaller prime factors were already divided out. Combined with the 6k ± 1 trick, we only need to go up to √n. See `articles/8.primeFactorsOfANumber.js`.

```JavaScript
const primeFactorsOfANumber = (num) => {
  let factors = new Set();
  let n = num;

  while (n % 2 === 0) { factors.add(2); n = n / 2; }
  while (n % 3 === 0) { factors.add(3); n = n / 3; }

  for (let i = 5; i * i <= n; i += 6) {
    while (n % i === 0) { factors.add(i); n = n / i; }
    while (n % (i + 2) === 0) { factors.add(i + 2); n = n / (i + 2); }
  }

  if (n > 3) factors.add(n);   // leftover prime greater than 3
  return factors;
};
```

### Why the leftover check?
After the loop, if n is still greater than 1, the remaining n itself is a prime factor (a number can have at most one prime factor greater than √n).

- **Time Complexity**: O(√n) — the loop runs up to √n, and divisions only shrink n.
- **Space Complexity**: O(number of distinct prime factors) for the result set.

## *Key Points to Remember*
1. **Divide repeatedly** by each divisor, not just once — a prime factor can appear many times (e.g. 8 = 2 × 2 × 2).
2. **No separate primality test needed**: composite divisors are never found because their prime factors were already removed.
3. **Check the remainder at the end**: if n > 1 after the loop, n is itself prime.
4. Use a `Set` if you only want distinct factors, or a list if you want the full factorization.

# **Conclusion**
Prime factorization is done in O(√n) by dividing out 2 and 3 first, then testing numbers of the form 6k ± 1 up to √n, and finally checking for a leftover prime.
