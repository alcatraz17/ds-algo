# **Factorial of a Number**

## *Introduction*
The factorial of a number n (written as n!) is the product of all positive integers from 1 to n. For example, 5! = 5 × 4 × 3 × 2 × 1 = 120. By definition, 0! = 1. Factorial can be computed iteratively (with a loop) or recursively.

## Approach 1: Iterative
Multiply the numbers from n down to 1 using a loop. See `articles/3.factorialOfANumber.js`.

```JavaScript
const factorial = (num) => {
  let factorial = 1;
  while (num > 0) {
    factorial = num * factorial;
    num--;
  }
  return factorial;
};
```

- **Time Complexity**: O(n).
- **Space Complexity**: O(1).

## Approach 2: Recursive
n! = n × (n - 1)!, with the base case 0! = 1! = 1. See `articles/3.factorialOfANumberRecursive.js`.

```JavaScript
function factorial(num) {
  if (num === 0 || num === 1) {
    return 1;
  }
  return num * factorial(num - 1);
}
```

- **Time Complexity**: O(n).
- **Space Complexity**: O(n) because of the recursion call stack.

## *Key Points to Remember*
1. **Factorial grows extremely fast**: 20! already overflows a 64-bit integer, so for large n the result loses precision in JavaScript.
2. **Base case matters**: without `num === 0 || num === 1` the recursion never stops.
3. **Iterative uses less space** (O(1)) than recursive (O(n) stack).
4. **Related problem**: counting digits of n! without computing it uses the log trick, see `problems/05.digitsOfAFactorial.js`.

# **Conclusion**
Both iterative and recursive factorial run in O(n) time. The recursive version is shorter but uses O(n) stack space. Remember that factorial overflows quickly, which is why many problems (like trailing zeros) avoid computing it directly.
