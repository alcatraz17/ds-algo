# **GCD — Greatest Common Divisor (Euclidean Algorithm)**

## *Introduction*
The GCD of two numbers is the largest number that divides both of them exactly. For example, gcd(12, 18) = 6. It is one of the oldest and most useful algorithms in mathematics.

## Approach 1: Basic Euclidean (repeated subtraction)
The idea: gcd(a, b) stays the same if we replace the larger number by the difference of the two. Keep subtracting the smaller from the larger until both become equal.

```JavaScript
const gcd = (a, b) => {
  while (a !== b) {
    if (a > b) a = a - b;
    else b = b - a;
  }
  return a;
};
```

- **Time Complexity**: O(max(a, b)) in the worst case (e.g. gcd(1, 1000000)).
- **Space Complexity**: O(1).

## Approach 2: Optimized Euclidean (using modulo)
Subtraction can be replaced by the modulo operation: gcd(a, b) = gcd(b, a % b). When b becomes 0, a is the answer. See `05.greatestCommonDivisor.js`.

```JavaScript
const gcd = (a, b) => {
  if (b === 0) {
    return a;
  }
  return gcd(b, a % b);
};
```

- **Time Complexity**: O(log(min(a, b))) — the numbers shrink very fast.
- **Space Complexity**: O(log(min(a, b))) for the recursion stack (O(1) if written with a loop).

## *Key Points to Remember*
1. **Euclidean idea**: gcd(a, b) = gcd(b, a % b), stop when b = 0.
2. **Modulo version is much faster** than repeated subtraction.
3. **GCD is the building block** for LCM, reducing fractions, and modular arithmetic.

# **Conclusion**
The optimized Euclidean algorithm finds the GCD in O(log(min(a, b))) time using repeated modulo. It is fast enough even for very large numbers and is used everywhere in number theory problems.
