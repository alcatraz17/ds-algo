# **All Divisors of a Number**

## *Introduction*
A divisor of n is a number that divides n exactly. For example, the divisors of 24 are 1, 2, 3, 4, 6, 8, 12, 24. Printing all divisors efficiently uses the same "divisors come in pairs" idea as the primality test.

## Naive Approach
Check every number from 1 to n.

```JavaScript
for (let i = 1; i <= n; i++) {
  if (n % i === 0) console.log(i);
}
```

- **Time Complexity**: O(n).
- **Space Complexity**: O(1).

## Efficient Approach: Loop up to √n
If i divides n, then n / i is also a divisor. So we only loop up to √n and print both i and n / i. See `09.allDivisorsOfANumber.js`.

```JavaScript
const allDivisors = (num) => {
  for (let i = 1; i * i <= num; i++) {
    if (num % i === 0) {
      console.log(i);
      if (i !== num / i) {
        console.log(num / i);
      }
    }
  }
};
```

- **Time Complexity**: O(√n).
- **Space Complexity**: O(1).
- **Note**: the `i !== num / i` check avoids printing √n twice for perfect squares (e.g. 36 → i = 6).
- **Downside**: the divisors do not come out in sorted order.

## Printing in Sorted Order (still O(√n))
Run two loops: the first prints the small divisors i (≤ √n) in increasing order, the second prints the large divisors n / i in increasing order by going downwards.

```JavaScript
const allDivisorsSorted = (num) => {
  let i;
  for (i = 1; i * i <= num; i++) {
    if (num % i === 0) console.log(i);
  }
  for (i = i - 1; i >= 1; i--) {
    if (num % i === 0 && i !== num / i) {
      console.log(num / i);
    }
  }
};
```

- **Time Complexity**: O(√n).
- **Space Complexity**: O(1).

## *Key Points to Remember*
1. **Divisors come in pairs** (i, n / i) around √n.
2. **Avoid duplicates for perfect squares** with the `i !== num / i` check.
3. **Two loops give sorted output** without storing anything.

# **Conclusion**
All divisors can be found in O(√n) by pairing each small divisor with its partner n / i. Using two loops, they can even be printed in sorted order with constant extra space.
