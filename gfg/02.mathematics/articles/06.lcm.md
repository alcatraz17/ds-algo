# **LCM — Least Common Multiple**

## *Introduction*
The LCM of two numbers is the smallest positive number that is a multiple of both. For example, lcm(4, 6) = 12.

## Naive Approach
Start from the larger of the two numbers and keep checking multiples until one is divisible by both.

```JavaScript
const lcm = (a, b) => {
  let res = Math.max(a, b);
  while (true) {
    if (res % a === 0 && res % b === 0) return res;
    res++;
  }
};
```

- **Time Complexity**: O(a × b) in the worst case.
- **Space Complexity**: O(1).

## Efficient Approach: Using GCD
There is a simple relation between GCD and LCM:

**a × b = gcd(a, b) × lcm(a, b)**

So `lcm(a, b) = (a × b) / gcd(a, b)`. See `06.leastCommonMultiple.js`.

```JavaScript
function lcm(a, b) {
  const gcdValue = (function gcd(d, f) {
    if (f === 0) {
      return d;
    }
    return gcd(f, d % f);
  })(a, b);

  return (a * b) / gcdValue;
}
```

- **Time Complexity**: O(log(min(a, b))) — same as the GCD computation.
- **Space Complexity**: O(log(min(a, b))) for the recursion stack.

## *Key Points to Remember*
1. **Golden formula**: `a × b = gcd(a, b) × lcm(a, b)`.
2. **Compute GCD first**, then derive LCM from it — never use the naive loop in practice.
3. **Watch out for overflow**: `(a * b)` can be large, so some languages prefer `(a / gcd) * b`.

# **Conclusion**
LCM is best computed through GCD using the formula a × b = gcd × lcm. This turns an O(a × b) brute force into an O(log n) solution.
