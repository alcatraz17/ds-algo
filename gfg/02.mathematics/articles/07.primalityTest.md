# **Primality Test**

## *Introduction*
A prime number is a number greater than 1 that has exactly two divisors: 1 and itself. For example, 2, 3, 5, 7, 11 are primes. The primality test checks whether a given number is prime.

## Approach 1: Naive — check every number
Try dividing n by every number from 2 to n - 1.

```JavaScript
const isPrime = (n) => {
  if (n < 2) return false;
  for (let i = 2; i < n; i++) {
    if (n % i === 0) return false;
  }
  return true;
};
```

- **Time Complexity**: O(n).
- **Space Complexity**: O(1).

## Approach 2: Check up to √n
Divisors come in pairs: if n = a × b and a ≤ √n, then b ≥ √n. So if n has any divisor, one of them must be ≤ √n. Checking up to √n is enough.

```JavaScript
for (let i = 2; i * i <= n; i++) {
  if (n % i === 0) return false;
}
```

- **Time Complexity**: O(√n).
- **Space Complexity**: O(1).

## Approach 3: 6k ± 1 Optimization
Every prime greater than 3 is of the form 6k − 1 or 6k + 1 (because 6k, 6k + 2, 6k + 4 are even and 6k + 3 is divisible by 3). So we check 2 and 3 directly, then only test numbers of the form 6k ± 1 up to √n. This cuts the checks to about one third. See `07.primeNumber.js`.

```JavaScript
const isPrime = (num) => {
  if (num < 2) return false;
  if (num === 2 || num === 3) return true;
  if (num % 2 === 0 || num % 3 === 0) return false;

  for (let i = 5; i * i <= num; i += 6) {
    if (num % i === 0) return false;
    if (num % (i + 2) === 0) return false;
  }
  return true;
};
```

- **Time Complexity**: O(√n), but roughly 3 times fewer iterations than Approach 2.
- **Space Complexity**: O(1).

## *Key Points to Remember*
1. **Only check divisors up to √n** — divisors come in pairs around √n.
2. **Handle small cases first**: n < 2 is not prime; 2 and 3 are prime.
3. **6k ± 1 skips multiples of 2 and 3**, making the loop three times cheaper.
4. **To test many numbers at once**, use the Sieve of Eratosthenes instead (see the next notes).

# **Conclusion**
Primality testing improves from O(n) to O(√n) by stopping at the square root, and the 6k ± 1 trick makes it three times faster in practice by skipping multiples of 2 and 3.
