# **Sieve of Eratosthenes**

## *Introduction*
The Sieve of Eratosthenes finds **all prime numbers up to n** in one go. Testing each number individually would cost O(n√n); the sieve does it much faster by marking off multiples instead of testing divisibility.

## How It Works
1. Create a boolean array of size n + 1, all set to `true` (0 and 1 are not prime).
2. Starting from 2, if a number i is still marked prime, cross out all its multiples i×i, i×i + i, ... — they cannot be prime.
3. Start crossing from i×i, because smaller multiples (2i, 3i, ...) were already crossed by smaller primes.
4. Stop the outer loop at √n — any composite ≤ n has a prime factor ≤ √n.
5. The numbers still marked `true` are the primes.

See `10.sieveOfEratosthenes.js`.

```JavaScript
const sieveOfEratosthenes = (num) => {
  let arr = new Array(num + 1).fill(true);
  let results = [];

  arr[0] = false;
  arr[1] = false;

  for (let i = 2; i * i <= num; i++) {
    if (arr[i]) {
      for (let j = i * i; j <= num; j += i) {
        arr[j] = false;
      }
    }
  }

  for (let k = 0; k <= num; k++) {
    if (arr[k]) results.push(k);
  }

  return results;
};
```

- **Time Complexity**: O(n log log n) — each prime p crosses out n/p numbers, and the sum of 1/p over primes grows very slowly.
- **Space Complexity**: O(n) for the boolean array.

## *Key Points to Remember*
1. **Mark multiples, not test divisibility** — that is the whole trick.
2. **Inner loop starts at i×i**, and the outer loop stops at √n.
3. **Great for many queries**: build the sieve once, then answer "is x prime?" in O(1).
4. **Used in problems** like counting numbers with exactly 3 divisors (squares of primes ≤ n), see `../problems/07.exact3Divisors.js`.

# **Conclusion**
The Sieve of Eratosthenes lists all primes up to n in O(n log log n) time and O(n) space. It is the standard tool whenever a problem asks about many primes or repeated primality queries in a range.
