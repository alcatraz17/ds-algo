# **Computing Power (x^n)**

## *Introduction*
Computing x raised to the power n (x^n) is a common sub-task in many problems. The naive way multiplies x by itself n times; binary exponentiation does the same in far fewer steps.

## Approach 1: Naive
Multiply x, n times in a loop.

```JavaScript
const power = (x, n) => {
  let res = 1;
  for (let i = 0; i < n; i++) {
    res = res * x;
  }
  return res;
};
```

- **Time Complexity**: O(n).
- **Space Complexity**: O(1).

## Approach 2: Binary Exponentiation (Recursive)
The key idea: use the halving rules

- if n is even: `x^n = (x^(n/2))^2`
- if n is odd: `x^n = x × (x^(n/2))^2`

Each step halves the exponent, so we only need about log2(n) steps. See `articles/11.powerOfNumber.js`.

```JavaScript
const computePower = (x, y) => {
  if (y === 0) return 1;

  let temp = computePower(x, Math.floor(y / 2));

  if (y % 2 === 0) {
    return temp * temp;
  }
  return x * temp * temp;
};
```

- **Time Complexity**: O(log n).
- **Space Complexity**: O(log n) for the recursion stack.

## Approach 3: Binary Exponentiation (Iterative)
Look at the exponent bit by bit. If the current bit is 1, multiply the current power of x into the result; then square x and shift to the next bit. See `articles/12.iterativePower.js`.

```JavaScript
const binaryExponentiation = (x, y) => {
  let result = 1;

  while (y > 0) {
    if (y & 1) {
      result = result * x;
    }
    y = y >> 1;
    x = x * x;
  }
  return result;
};
```

### Example: 2^13 (13 = 1101 in binary)
1. Bit 1: result = 2, x becomes 2^2 = 4.
2. Bit 0: skip, x becomes 4^2 = 16.
3. Bit 1: result = 2 × 16 = 32, x becomes 16^2 = 256.
4. Bit 1: result = 32 × 256 = 8192 = 2^13.

- **Time Complexity**: O(log n).
- **Space Complexity**: O(1).

## *Key Points to Remember*
1. **Every exponent is a sum of powers of 2** — that is why squaring and selected multiplications work.
2. **Iterative version is preferred**: same O(log n) time but O(1) space.
3. **With modulo**: take `% m` after every multiplication to keep numbers small.

# **Conclusion**
Binary exponentiation reduces power computation from O(n) to O(log n) by squaring at each step and multiplying only when a bit of the exponent is set. It is a must-know technique, especially combined with modular arithmetic.
