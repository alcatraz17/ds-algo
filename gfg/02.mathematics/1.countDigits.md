# **Count Digits in a Number**

## *Introduction*
Counting digits means finding how many digits a number has. For example, 1234 has 4 digits and 7 has 1 digit. It is a basic warm-up problem that teaches how to break a number down digit by digit.

## Approaches

### 1. Iterative (divide by 10)
Keep dividing the number by 10 and count how many times you can do it before it becomes 0. See `articles/1.numberOfDigits.js`.

```JavaScript
const numberOfDigits = (num) => {
  let digits = 0;
  while (num > 0) {
    num = Math.floor(num / 10);
    digits++;
  }
  return digits;
};
```

- **Time Complexity**: O(d) where d is the number of digits, which is O(log10(n)).
- **Space Complexity**: O(1).

### 2. Using logarithm
For a positive number, digits = `Math.floor(Math.log10(num)) + 1`.

```JavaScript
const countDigits = (num) => Math.floor(Math.log10(num)) + 1;
```

- **Time Complexity**: O(1).
- **Space Complexity**: O(1).

## *Key Points to Remember*
1. **Dividing by 10 removes the last digit**: `Math.floor(123 / 10)` gives 12.
2. **Handle 0 separately**: it has 1 digit, but the loop skips it.
3. **Digit count grows logarithmically**: a number n has roughly log10(n) + 1 digits.

# **Conclusion**
Counting digits is a simple loop that repeatedly removes the last digit. Both the loop and the logarithm trick are fast, and the idea of "peeling off digits one by one" is reused in many other problems like palindrome check and digit sum.
