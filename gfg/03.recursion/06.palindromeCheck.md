# **Palindrome Check Using Recursion**

## *Introduction*
A palindrome is a string that reads the same forwards and backwards (like `"abba"` or `"madam"`). The recursive idea: a string is a palindrome if its first and last characters match **and** the substring between them is also a palindrome.

## Writing the Base Case
1. **Empty or single-character string**: A string of length 0 or 1 is always a palindrome. In the two-pointer version, this happens when the start index meets or crosses the end index: `start >= end`.
2. **Mismatch case**: If `str[start] !== str[end]`, the answer is immediately `false` — no more recursion needed.

## Implementation
See `articles/07.palindrome.js`:

```JavaScript
function isPal(str, start, end) {
  if (start >= end) {   // base case: pointers met or crossed
    return true;
  }

  return str[start] === str[end] && isPal(str, start + 1, end - 1);
}

console.log(isPal('abba', 0, 3)); // true
```

**How it works**: Two pointers start at both ends of the string. Each call compares the characters at those positions, then moves both pointers one step inward. If any pair mismatches, `&&` short-circuits and returns `false` up the chain.

**Trace** for `'abba'`: compare `a` vs `a` (match) → compare `b` vs `b` (match) → `start >= end` → return `true`.

## Key Points to Remember
1. **Two pointers moving inward**: Passing indices instead of slicing the string avoids creating new strings on every call — important because `str.slice(1, -1)` would cost O(n) per call.
2. **Short-circuit with `&&`**: A single mismatch stops the recursion early, which is the "second base case" in disguise.
3. **Works for any even/odd length**: When the length is odd, the pointers land on the same middle character (`start === end`), which trivially matches itself.

## Complexity
- **Time Complexity: O(n)** — each character is compared at most once.
- **Space Complexity: O(n)** — the call stack holds up to n/2 frames, which simplifies to O(n).

# **Conclusion**
The recursive palindrome check compares the outer pair of characters and recurses on the inner substring, using `start >= end` as the base case. It takes O(n) time and O(n) stack space, and passing indices keeps it free of costly string slicing.
