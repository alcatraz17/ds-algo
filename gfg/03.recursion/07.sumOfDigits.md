# **Sum of Digits Using Recursion**

## *Introduction*
The sum of digits of a number like `253` is `2 + 5 + 3 = 10`. The recursive idea: the sum of digits of `n` is the **last digit** plus the **sum of digits of the remaining number**. We peel digits off one at a time using modulo and integer division.

## Writing the Base Case
1. **Smallest meaningful input**: A single-digit number (0–9). Its digit sum is the number itself, so we return it directly.
2. **Every call shrinks the input**: `Math.floor(n / 10)` removes one digit per call, so the number always reaches a single digit.

## Implementation
See `articles/08.sumOfDigits.js`:

```JavaScript
function sumOfDigits(n) {
  if (n <= 9) {         // base case: single digit
    return n;
  }

  let lastDigit = n % 10;
  let remaining = Math.floor(n / 10);

  return sumOfDigits(remaining) + lastDigit;
}

console.log(sumOfDigits(253)); // 10
```

**Trace**: `sumOfDigits(253) = sumOfDigits(25) + 3 = (sumOfDigits(2) + 5) + 3 = 2 + 5 + 3 = 10`.

## Key Points to Remember
1. **`n % 10` gives the last digit**: Modulo by 10 isolates the units digit (e.g. `253 % 10 = 3`).
2. **`Math.floor(n / 10)` drops the last digit**: Integer division removes the units digit (e.g. `253 / 10 → 25`). JavaScript has no integer division operator, so `Math.floor` (or `Math.trunc` for negatives) is needed.
3. **Base case options**: You can stop at a single digit (`n <= 9`, return `n`) or at zero (`n === 0`, return `0`) — both are correct; stopping at a single digit saves one call.
4. **Same pattern reappears**: Counting digits (`problems/03.countDigits.js`), reversing a number (`problems/04.reversePower.js`), and digital root (`problems/06.digitalRoot.js`) all reuse this modulo-and-divide recursion.

## Complexity
- **Time Complexity: O(d)** where d is the number of digits — one call per digit. Since d = log₁₀(n), this is also written as **O(log n)**.
- **Space Complexity: O(d) = O(log n)** — the call stack holds one frame per digit.

# **Conclusion**
Sum of digits is the standard "peel one digit per call" recursion: take `n % 10` as the current digit's contribution and recurse on `Math.floor(n / 10)`, stopping at a single digit. It runs in O(log n) time and space because a number has only log₁₀(n) digits.
