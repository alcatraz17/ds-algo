# **Tower of Hanoi**

## *Introduction*
**Problem**: There are three rods (A, B, C) and `n` disks of different sizes stacked on rod A, largest at the bottom. Move the whole stack to rod C, following two rules:
1. Only one disk can be moved at a time.
2. A larger disk can never be placed on top of a smaller disk.

Rod B is used as a helper. The minimum number of moves required is **2ⁿ - 1**.

## Recursive Idea
To move n disks from source (A) to destination (C) using helper (B):
1. **Move the top n - 1 disks** from A to B (using C as helper) — recursive call.
2. **Move the largest disk** from A to C — a single direct move.
3. **Move the n - 1 disks** from B to C (using A as helper) — recursive call.

```JavaScript
function towerOfHanoi(n, from, to, helper) {
  if (n === 0) return;      // base case: nothing to move

  towerOfHanoi(n - 1, from, helper, to);   // step 1: n-1 disks to helper
  console.log(`Move disk ${n} from ${from} to ${to}`); // step 2: largest disk
  towerOfHanoi(n - 1, helper, to, from);   // step 3: n-1 disks to destination
}

towerOfHanoi(3, 'A', 'C', 'B');
// Move disk 1 from A to C
// Move disk 2 from A to B
// Move disk 1 from C to B
// Move disk 3 from A to C
// Move disk 1 from B to A
// Move disk 2 from B to C
// Move disk 1 from A to C
```

## Key Points to Remember
1. **Base case**: `n === 0` (or `n === 1`, where you just move the single disk directly). With nothing to move, simply return.
2. **Trust the recursion**: You never figure out the full move sequence yourself — you only handle moving the largest disk, and let the two recursive calls handle the rest.
3. **Roles rotate between calls**: Source, destination, and helper swap roles in each recursive call. Passing them as parameters is what makes the solution elegant.
4. **2ⁿ - 1 moves**: The recurrence `T(n) = 2·T(n-1) + 1` solves to 2ⁿ - 1. For 3 disks: 7 moves; for 10 disks: 1023 moves.

## Complexity
- **Time Complexity: O(2ⁿ)** — each disk level doubles the work; total moves are 2ⁿ - 1.
- **Space Complexity: O(n)** — the recursion depth is n (only n frames are on the stack at once, even though 2ⁿ calls happen in total).

# **Conclusion**
Tower of Hanoi is the flagship example of divide-and-conquer recursion: move the top n-1 disks aside, move the largest disk, then move the n-1 disks back on top. It needs exactly 2ⁿ - 1 moves (exponential time) but only O(n) stack space, and it beautifully shows how "trusting the recursive case" solves a problem that looks overwhelming iteratively.
