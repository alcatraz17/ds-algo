# **Josephus Problem**

## *Introduction*
**Problem**: `n` people stand in a circle, numbered `0` to `n - 1`. Starting from person 0, every **k-th** person is eliminated, counting continues from the next person, and the circle keeps shrinking. Find the position of the **last person remaining**.

**Example**: `n = 5, k = 3` → eliminations are 2, 0, 4, 1 → the survivor is **3** (using 0-based indexing).

## Recursive Idea
The key insight is **relabeling after each elimination**. If `josephus(n - 1, k)` tells us the survivor among `n - 1` people, then after one person is eliminated, all positions shift by `k`. So the survivor among `n` people is:

```
josephus(n, k) = (josephus(n - 1, k) + k) % n
```

The `% n` wraps the shifted position around the circle.

```JavaScript
function josephus(n, k) {
  if (n === 1) return 0;   // base case: one person left, they survive

  return (josephus(n - 1, k) + k) % n;
}

console.log(josephus(5, 3)); // 3
```

**Trace** for `n = 5, k = 3`: `josephus(1) = 0` → `josephus(2) = (0 + 3) % 2 = 1` → `josephus(3) = (1 + 3) % 3 = 1` → `josephus(4) = (1 + 3) % 4 = 0` → `josephus(5) = (0 + 3) % 5 = 3`.

## Key Points to Remember
1. **Base case**: With one person, that person survives at position 0 (0-based).
2. **The answer is built on the way back**: Unlike most problems, the input grows (n - 1 → n) as the calls return — the `+ k` shift is applied while the stack unwinds.
3. **0-based vs 1-based**: This formula uses 0-based positions. For 1-based answers, compute the 0-based result and add 1.
4. **Special case k = 2**: For the classic version where every 2nd person is killed, there is a bit-manipulation shortcut: write `n = 2^m + l` and the answer is `2l + 1` (1-based).
5. **Related flavor**: `../problems/07.luckyNumber.js` uses the same circle-elimination idea — positions are removed in passes and the survivors are relabeled each round.

## Complexity
- **Time Complexity: O(n)** — one recursive call per person removed.
- **Space Complexity: O(n)** — the call stack holds n frames at its deepest.

# **Conclusion**
The Josephus problem is solved by a one-line recurrence: the survivor among n people is the survivor among n - 1 people, shifted by k and wrapped with modulo. It runs in O(n) time and O(n) stack space, and it demonstrates how a recursive answer can be constructed while the call stack unwinds rather than while it grows.
