# **Generating Subsets / Subsequences of a String**

## *Introduction*
**Problem**: Print all subsets (also called subsequences or the power set) of a string. For `"abc"`, the output is: `""`, `"a"`, `"b"`, `"c"`, `"ab"`, `"ac"`, `"bc"`, `"abc"` — a total of **2ⁿ** subsets, because every character is either **included or excluded**.

## Recursive Idea
Walk through the string one character at a time, carrying a `current` string built so far. At each character, make **two recursive calls** — one that skips the character, one that includes it:

```JavaScript
function subsets(str, current = '', index = 0) {
  if (index === str.length) {  // base case: no characters left
    console.log(current);
    return;
  }

  subsets(str, current, index + 1);                // exclude str[index]
  subsets(str, current + str[index], index + 1);   // include str[index]
}

subsets('abc');
// prints: "", "c", "b", "bc", "a", "ac", "ab", "abc" (order may vary)
```

## How It Works
1. **Binary choice per character**: Every position doubles the number of paths — include or exclude — forming a binary recursion tree of height n.
2. **Base case at the end of the string**: When `index === str.length`, the `current` string is one complete subset, so we print it.
3. **Leaf nodes = subsets**: A string of length n produces exactly 2ⁿ leaves, and each leaf is one subset.

## Key Points to Remember
1. **2ⁿ subsets**: The total count is 2 raised to the string length — useful as a quick correctness check.
2. **The empty string is a valid subset**: The path that excludes every character produces `""`.
3. **Exclude before include** (or vice versa): The order of the two recursive calls only changes the printing order, not the set of results.
4. **Same pattern as subset-sum and 0/1 knapsack**: "For each item, take it or leave it" is one of the most reused recursion templates.

## Complexity
- **Time Complexity: O(2ⁿ · n)** — there are 2ⁿ subsets, and building/printing each string costs up to O(n).
- **Space Complexity: O(n)** — the recursion tree is n levels deep, so the call stack holds at most n frames (not counting the output strings).

# **Conclusion**
Generating subsets is the classic two-branch recursion: for each character, recurse once excluding it and once including it, printing when the string is exhausted. It produces all 2ⁿ subsets in exponential time with O(n) stack depth, and its include/exclude template powers many later backtracking problems.
