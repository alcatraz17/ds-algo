# **Print N to 1 and 1 to N Using Recursion**

## *Introduction*
Printing numbers from N down to 1 (and from 1 up to N) are the classic first recursion exercises. They teach the most important lesson of recursion: **where you place the work relative to the recursive call decides when it happens** — on the way down the call stack, or on the way back up.

## Print N to 1
Print before the recursive call, so printing happens while the stack is still growing. See `articles/03.nTo1.js`:

```JavaScript
function nToOne(n) {
  if (n === 1) {        // base case
    return 1;
  }

  console.log(n);       // work happens on the way down
  return nToOne(n - 1);
}

nToOne(5); // prints 5, 4, 3, 2
```

**How it works**: `nToOne(5)` prints 5, then calls `nToOne(4)` which prints 4, and so on, until the base case stops the chain.

## Print 1 to N
Print after the recursive call, so printing happens while the stack is unwinding. See `articles/04.1ToN.js` and `problems/01.oneToN.js`:

```JavaScript
function oneToN(n) {
  if (n === 0) {        // base case
    return;
  }

  oneToN(n - 1);        // go all the way down first
  console.log(n);       // work happens on the way back up
}

oneToN(5); // prints 1, 2, 3, 4, 5
```

**How it works**: `oneToN(5)` calls `oneToN(4)`, which calls `oneToN(3)`, all the way to `oneToN(0)` (the base case). Only then do the waiting frames print: the deepest waiting frame holds `n = 1`, so 1 prints first, then 2, then 3, and so on.

## Key Points to Remember
1. **Code before the call runs top-down**: statements placed before the recursive call execute in the order the calls are made (N to 1).
2. **Code after the call runs bottom-up**: statements placed after the recursive call execute in reverse call order (1 to N), because each frame resumes only after its child call returns.
3. **Base case stops the chain**: For N to 1 the base case is `n === 1`; for 1 to N it is `n === 0`. Both must be reachable, or the recursion never ends.

## Complexity
- **Time Complexity: O(n)** — the function is called once for each number from n down to the base case.
- **Space Complexity: O(n)** — the call stack holds n frames at its deepest point.

# **Conclusion**
N to 1 and 1 to N differ by a single line's position: print before the recursive call to go downward, print after it to go upward. This simple trick of ordering work around the recursive call is used in almost every recursion problem.
