# **Sum of First N Natural Numbers (Recursion)**

## *Introduction*
The sum of the first N natural numbers is `1 + 2 + 3 + ... + N`. Recursively, the idea is simple: the sum up to `n` is `n` plus the sum up to `n - 1`. This is a great example for learning how to choose a correct **base case**.

## Writing the Base Case
1. **Find the smallest meaningful input**: For this problem, that is `n = 1`, where the sum is obviously 1.
2. **Make sure every call reaches it**: Since each call reduces `n` by 1, any positive starting value eventually becomes 1.
3. **Return a concrete value**: The base case must return an actual answer (here `1`), not make another recursive call.

## Implementation
See `articles/06.naturalNumSum.js`:

```JavaScript
function sumRec(n) {
  if (n === 1) {        // base case: sum of first 1 natural number is 1
    return 1;
  }

  return n + sumRec(n - 1); // recursive case: n + sum of the rest
}

console.log(sumRec(5)); // 15
```

**Trace**: `sumRec(5) = 5 + sumRec(4) = 5 + 4 + sumRec(3) = ... = 5 + 4 + 3 + 2 + 1 = 15`.

## Tail-Recursive Variant
An accumulator version (from the same file) avoids pending additions, though real JS engines still use one stack frame per call:

```JavaScript
function sumTail(n, acc = 0) {
  if (n == 0) {
    return acc;
  }

  return sumTail(n - 1, n + acc);
}
```

Note the base case changes to `n == 0` (returning the accumulated sum), since the addition now happens inside the parameter, not after the call.

## Key Points to Remember
1. **One base case is enough here**: A single check `n === 1` (or `n == 0` for the tail version) covers the whole input range of positive integers.
2. **Trust the recursive case**: Assume `sumRec(n - 1)` correctly returns the sum of the first `n - 1` numbers, then just add `n`. This "recursive leap of faith" is how you design recursive solutions.
3. **Guard the input**: If `n` could be 0 or negative, add a check like `if (n <= 0) return 0;` to avoid infinite recursion.

## Complexity
- **Time Complexity: O(n)** — one recursive call per number.
- **Space Complexity: O(n)** — the call stack holds n frames at its deepest. (The mathematical formula `n * (n + 1) / 2` solves the same problem in O(1) time and space.)

# **Conclusion**
The sum of first N natural numbers shows the standard recursive pattern: pick the smallest input as the base case, express the answer as "current value plus the answer for the rest", and let the call stack do the adding. It runs in O(n) time and O(n) stack space.
