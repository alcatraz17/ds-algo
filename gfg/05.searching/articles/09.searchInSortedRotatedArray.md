# **Search in a Sorted Rotated Array**

## *Introduction*
A sorted rotated array is a sorted array that has been shifted around a pivot. Example: `[4, 5, 6, 7, 0, 1, 2]` is `[0, 1, 2, 4, 5, 6, 7]` rotated at index 4. The task is to find a target element in O(log n) time.

## The Key Idea
1. **One half is always sorted**: For any `mid`, either the left half (`low` to `mid`) or the right half (`mid` to `high`) is fully sorted — sometimes both.
2. **Check the sorted half**: If the target lies inside the sorted half's range, search there; otherwise search the other half.
3. **Repeat** like normal binary search until found or the range is empty.

```javascript
function searchRotated(arr, target) {
  let low = 0;
  let high = arr.length - 1;

  while (low <= high) {
    let mid = Math.floor((low + high) / 2);

    if (arr[mid] === target) return mid;

    if (arr[low] <= arr[mid]) {
      // left half is sorted
      if (target >= arr[low] && target < arr[mid]) {
        high = mid - 1;
      } else {
        low = mid + 1;
      }
    } else {
      // right half is sorted
      if (target > arr[mid] && target <= arr[high]) {
        low = mid + 1;
      } else {
        high = mid - 1;
      }
    }
  }
  return -1;
}

console.log(searchRotated([4, 5, 6, 7, 0, 1, 2], 0)); // 4
```

## Key Points to Remember
1. **Why it works**: Even though the whole array is not sorted, the sorted half gives a clean range check (`arr[low] <= target < arr[mid]`), so we can still discard half the array each step.
2. **Time complexity O(log n)**: One half is eliminated in every iteration.
3. **Space complexity O(1)**: Iterative version uses only pointers.
4. **Alternative approach**: First binary search for the pivot (smallest element), then run a normal binary search on the correct half. Same O(log n) time, but two passes.

## Naive Approach
Linear search works regardless of rotation but takes O(n) time.

# **Conclusion**
Searching a sorted rotated array still achieves O(log n) by noticing that one half of every range is always sorted. Check whether the target lies in that sorted half, and discard the other half accordingly. Space stays O(1).
