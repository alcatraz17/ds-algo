# **Index of Last Occurrence**

## *Introduction*
This is the mirror image of the first occurrence problem: in a sorted array with duplicates, find the **rightmost** index where the target appears. Example: in `[1, 2, 3, 4, 5, 6, 7, 7, 7, 7, 7]`, the last occurrence of 7 is index 10.

## How It Works
1. **Run a normal binary search** until `arr[mid] === element`.
2. **Check if mid is the last occurrence**: It is the last if `mid === arr.length - 1` (target at the very end) **or** `arr[mid + 1] !== element` (next element is different). Return `mid`.
3. **Otherwise keep looking right**: Set `low = mid + 1`, because a later occurrence must exist on the right.
4. **If not found**, return -1.

```javascript
function lastOccurrence(arr, element) {
  let low = 0;
  let high = arr.length - 1;

  while (low <= high) {
    let mid = Math.floor((low + high) / 2);

    if (arr[mid] === element) {
      if (mid === arr.length - 1 || arr[mid + 1] !== element) {
        return mid;
      } else {
        low = mid + 1; // a later 7 exists on the right
      }
    } else if (arr[mid] < element) {
      low = mid + 1;
    } else {
      high = mid - 1;
    }
  }
  return -1;
}

console.log(lastOccurrence([1, 2, 3, 4, 5, 6, 7, 7, 7, 7, 7], 7)); // 10
```
See `04.lastOccurrence.js`.

## Key Points to Remember
1. **Symmetric to first occurrence**: The only real changes are checking `arr[mid + 1]` instead of `arr[mid - 1]`, and moving `low` right instead of moving `high` left.
2. **Boundary check matters**: `mid === arr.length - 1` guards against reading past the end of the array.
3. **Time complexity O(log n)**: Same halving behavior as plain binary search.
4. **Space complexity O(1)** for the iterative version.

## Naive Approach
Scanning from the right end with a linear search also finds the last occurrence, but takes O(n) time in the worst case.

# **Conclusion**
Last occurrence search is binary search plus one extra check: when the target is found, look at the next element — if it matches, keep searching right. Time stays O(log n) and space stays O(1).
