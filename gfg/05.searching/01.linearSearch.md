# **Linear Search**

## *Introduction*
Linear search is the simplest searching technique. We go through the array element by element from the start and compare each element with the target value. If we find a match, we return the index. If we reach the end without a match, we return -1.

## How It Works
1. **Start at index 0**: Compare the first element with the target.
2. **Move one step at a time**: If the element does not match, move to the next index.
3. **Stop when found**: Return the index as soon as a match is found.
4. **Return -1 if not found**: If the loop finishes without a match, the element is not in the array.

```javascript
function findElement(arr, element) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === element) {
      return i;
    }
  }
  return -1;
}

console.log(findElement([1, 2, 45, 4, 89, 8], 2)); // 1
```
See `problems/01.findElement.js` for the full example.

## Key Points to Remember
1. **No sorting needed**: Works on any array, sorted or unsorted.
2. **Best case O(1)**: Target is at the first index.
3. **Worst case O(n)**: Target is at the last index or not present.
4. **Average case O(n)**: On average we scan half the array.
5. **Space complexity O(1)**: Only a loop variable is used.

## When to Use Linear Search
1. **Unsorted data**: When the array is not sorted and sorting it would cost more than a single search.
2. **Small arrays**: When n is small, the simple loop is fine.
3. **Single search**: When you search only once, sorting first (O(n log n)) is not worth it.

# **Conclusion**
Linear search checks elements one by one, so it runs in O(n) time with O(1) space. It is the go-to method for unsorted arrays or one-time searches, but for sorted arrays and repeated searches, binary search is much faster.
