# **Count Occurrences in a Sorted Array**

## *Introduction*
Given a sorted array with duplicates, count how many times a target element appears. Example: in `[1, 2, 3, 4, 5, 6, 7, 7, 7, 7, 7]`, the element 7 occurs 5 times.

## The Key Idea
1. **All duplicates sit together**: Because the array is sorted, every copy of the target forms one continuous block.
2. **Count = last - first + 1**: If we find the first and last occurrence indexes, the count is simply `lastIndex - firstIndex + 1`.
3. **Reuse the two searches**: Use the first occurrence and last occurrence binary searches we already learned.

```javascript
function countOccurrences(arr, ele) {
  const first = firstOccurrence(arr, ele);
  const last = lastOccurrence(arr, ele);

  if (first === -1 || last === -1) {
    return -1; // element not present
  }

  return last - first + 1;
}

console.log(countOccurrences([1, 2, 3, 4, 5, 6, 7, 7, 7, 7, 7], 7)); // 5
```
See `articles/05.countOccurences.js`, which reuses `firstOccurrence` and `lastOccurrence` from the earlier files.

## Key Points to Remember
1. **Not found case**: If the first occurrence search returns -1, the element does not exist at all; return -1 (or 0, depending on the problem statement).
2. **Time complexity O(log n)**: Two binary searches, each O(log n), so O(log n) + O(log n) = O(log n).
3. **Space complexity O(1)**: Iterative searches use no extra memory.

## Naive Approach
Scan the whole array and count matches in O(n) time, or find one match with binary search and then expand left and right — but that expanding step can take O(n) if the whole array is the same value. Using two proper binary searches keeps the total at O(log n).

# **Conclusion**
Counting occurrences in a sorted array is a direct application of first and last occurrence search: `count = lastIndex - firstIndex + 1`. It runs in O(log n) time and O(1) space, which beats the O(n) linear scan.
