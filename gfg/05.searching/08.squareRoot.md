# **Square Root Using Binary Search**

## *Introduction*
Given a number `n`, find its integer (floor) square root — the largest integer `x` such that `x * x <= n`. Example: for `n = 10`, the answer is 3, because 3² = 9 ≤ 10 but 4² = 16 > 10.

## The Key Idea
1. **The answer space is sorted**: The candidates 1, 2, 3, ..., n/2 form a sorted range, and the condition `mid * mid <= n` is true up to the answer and false after it. So we can binary search the answer.
2. **Search range**: For `n >= 2`, the square root is at most `n / 2`, so we search in `[1, n/2]`.
3. **Track the best candidate**: Whenever `mid * mid <= n`, save `mid` as a possible answer and try bigger values on the right.

```javascript
function sq(num) {
  if (num === 0 || num === 1) return num;

  let ans;
  let start = 1;
  let end = num / 2;

  while (start <= end) {
    let mid = Math.floor((start + end) / 2);
    let sqr = mid * mid;

    if (sqr === num) {
      return mid; // perfect square
    }

    if (sqr < num) {
      start = mid + 1;
      ans = mid; // best floor value so far
    } else {
      end = mid - 1;
    }
  }
  return ans;
}

console.log(sq(10)); // 3
```
See `articles/06.squareRoot.js` and `problems/04.perfectSquareRoot.js`.

## Key Points to Remember
1. **Why store `ans`?**: When `n` is not a perfect square, the loop ends without an exact match; `ans` holds the largest `mid` whose square was still ≤ n — exactly the floor of the root.
2. **Time complexity O(log n)**: We binary search a range of size n/2.
3. **Space complexity O(1)**: Only a few variables.
4. **Same pattern elsewhere**: This "binary search on the answer" pattern works for many problems where the condition flips from true to false at the answer (e.g. floor of x in `problems/06.lessThanEqualToN.js`).

## Naive Approach
Check every `i` from 1 upward until `i * i > n` in O(√n) time. Binary search improves this to O(log n).

# **Conclusion**
The integer square root can be found by binary searching the range [1, n/2] and remembering the largest value whose square does not exceed n. Time is O(log n) and space is O(1).
