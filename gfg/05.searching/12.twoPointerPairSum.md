# **Two-Pointer Technique — Pair Sum in a Sorted Array**

## *Introduction*
Given a **sorted** array and a target sum, find whether two elements add up to the target. Example: in `[2, 5, 8, 12, 30]` with sum 17, the pair (5, 12) works.

## The Key Idea
1. **Place two pointers**: `left` at the start (smallest element) and `right` at the end (largest element).
2. **Compare the pair sum with the target**:
   - If `arr[left] + arr[right] === target`: found the pair.
   - If the sum is **too small**: move `left` right — only a bigger element can increase the sum.
   - If the sum is **too big**: move `right` left — only a smaller element can decrease the sum.
3. **Sorted order makes the moves safe**: Because the array is sorted, we know exactly which pointer to move to push the sum up or down.

```javascript
function pairSum(arr, target) {
  let left = 0;
  let right = arr.length - 1;

  while (left < right) {
    let sum = arr[left] + arr[right];

    if (sum === target) {
      return [arr[left], arr[right]];
    } else if (sum < target) {
      left++;
    } else {
      right--;
    }
  }
  return null; // no pair found
}

console.log(pairSum([2, 5, 8, 12, 30], 17)); // [5, 12]
```

## Key Points to Remember
1. **Only one pass**: The pointers move toward each other and never go back, so at most n steps happen.
2. **Time complexity O(n)**: Better than the O(n²) brute force of checking every pair.
3. **Space complexity O(1)**: No hash map or extra storage needed.
4. **Requires sorted input**: For an unsorted array, sort first (O(n log n)) or use a hash set (O(n) time, O(n) space).

## Comparison with Other Approaches
1. **Brute force**: Two nested loops — O(n²) time, O(1) space.
2. **Hash set**: Store seen values — O(n) time, O(n) space, works on unsorted arrays too.
3. **Two pointers**: O(n) time, O(1) space — best when the array is already sorted.

# **Conclusion**
The two-pointer technique solves the pair sum problem in one pass by shrinking the range from both ends. For sorted arrays it gives O(n) time with O(1) space, no extra data structure needed.
