# **Leaders in an Array**

## *Introduction*
An element is a **leader** if it is greater than every element to its right. The last element is always a leader because there is nothing to its right. Example: in `[16, 17, 4, 3, 5, 2]` the leaders are `17, 5, 2`.

## *Idea (Right to Left)*
1. **Start from the right end** and treat the last element as the current maximum (`currLeader`).
2. **Move left**: whenever an element is bigger than `currLeader`, it is a leader — record it and update `currLeader`.
3. **The leaders are collected in reverse order** (right to left); reverse the result if left-to-right order is required.

### Code

```JavaScript
function leaders(arr) {
  const n = arr.length;
  let currLeader = arr[n - 1];
  const result = [currLeader];

  for (let i = n - 2; i >= 0; i--) {
    if (arr[i] > currLeader) {
      currLeader = arr[i];
      result.push(currLeader);
    }
  }

  return result.reverse();   // left-to-right order
}
```

## *Analysis*
1. **Time Complexity: O(n)** — one backward pass (plus an optional O(n) reverse).
2. **Space Complexity: O(1)** extra, ignoring the output array.
3. **Naive approach**: for each element, check all elements to its right — O(n²). Too slow.

## *Key Points to Remember*
1. **Scan direction matters**: leaders are defined by the right side, so scan from right to left to carry the "max so far from the right".
2. **The last element is always a leader.**
3. **Strictly greater** (`>`) means equal values are not leaders; adjust to `>=` if the problem says so.
4. **Output order**: right-to-left scan produces leaders in reverse — remember to flip if needed.

# **Conclusion**
Leaders are found in one backward pass by tracking the maximum seen so far from the right. This reduces the naive O(n²) check-everything approach to O(n) time with O(1) extra space.
