# **Maximum Difference (arr[j] − arr[i] with j > i)**

## *Introduction*
Find the largest value of `arr[j] − arr[i]` such that `j > i` — that is, buy low and sell high where the "sell" must come **after** the "buy". Example: in `[2, 3, 10, 6, 4, 8, 1]` the answer is `10 − 2 = 8`.

## *Idea*
1. **Track the minimum value seen so far** (`minVal`) as you scan left to right.
2. **At each element**, the best difference ending here is `arr[i] − minVal`; keep the maximum of these.
3. **Update `minVal`** if the current element is smaller.

### Code

```JavaScript
function maxDiff(arr) {
  let minVal = arr[0];
  let result = arr[1] - arr[0];

  for (let i = 1; i < arr.length; i++) {
    result = Math.max(result, arr[i] - minVal);
    minVal = Math.min(minVal, arr[i]);
  }

  return result;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — single pass.
2. **Space Complexity: O(1)** — two variables only.
3. **Naive approach**: try every pair (i, j) with j > i — O(n²).

## *Key Points to Remember*
1. **Order matters**: this is not max − min of the whole array, because the smaller element must come first. In `[7, 9, 5, 6, 3, 2]` the answer is `9 − 7 = 2`, not `9 − 2`.
2. **Related but different problem**: `problems/03.maxIndexDiff.js` maximizes the *index gap* `j − i` where `arr[i] ≤ arr[j]`, using precomputed `leftMinimum` and `rightMaximum` arrays — that one runs in O(n) time and O(n) space.
3. **Update the answer before updating `minVal`** so the current element acts as the "sell", never as both buy and sell.

# **Conclusion**
The maximum difference with j > i is found in one pass by keeping the minimum value seen so far and checking each element against it: O(n) time, O(1) space. The key insight is that for each position you only need the best (smallest) buy price before it.
