# **Stock Buy and Sell**

## *Introduction*
Given an array of stock prices where `arr[i]` is the price on day i, find the maximum profit from buying and selling multiple times (you must sell before buying again). Example: prices `[1, 5, 3, 8, 12]` give profit `(5−1) + (12−3) = 13`.

## *Idea (Accumulate Every Rise)*
1. **Walk through consecutive pairs** of days.
2. **Whenever tomorrow's price is higher than today's**, add the difference to the profit — it is as if you bought today and sold tomorrow.
3. **Sum of all small rises = profit of full valleys-to-peaks**, because consecutive rises add up: `(5−1) + (8−5) = 8−1`.

### Code

```JavaScript
function maxProfit(prices) {
  let profit = 0;

  for (let i = 1; i < prices.length; i++) {
    if (prices[i] > prices[i - 1]) {
      profit += prices[i] - prices[i - 1];
    }
  }

  return profit;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — single pass.
2. **Space Complexity: O(1)** — one accumulator.
3. **Equivalent "valley–peak" approach**: buy at every local minimum, sell at every local maximum — same O(n), slightly trickier loop conditions. The pair-sum version above is simpler and provably identical.

## *Key Points to Remember*
1. **This is the unlimited-transactions version** of the problem; the single-transaction version is exactly the "maximum difference with j > i" problem from note 10.
2. **Greed works here** because you can transact freely — every upward edge is capturable profit.
3. **Strictly greater** comparison: equal prices give zero profit and can be skipped.

# **Conclusion**
With unlimited transactions, maximum profit is simply the sum of every positive day-to-day price increase: O(n) time, O(1) space. The trick is realizing that chaining small rises equals holding from valley to peak.
