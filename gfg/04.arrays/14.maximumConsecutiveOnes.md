# **Maximum Consecutive 1s**

## *Introduction*
Given a binary array (only 0s and 1s), find the length of the longest run of consecutive 1s. Example: `[0, 1, 1, 0, 1, 1, 1]` gives `3`.

## *Idea*
1. **Keep a running count** of the current streak.
2. **On seeing a 1**, increment the count and update the best answer.
3. **On seeing a 0**, reset the count to 0 — the streak is broken.

### Code

```JavaScript
function maxConsecutiveOnes(arr) {
  let count = 0;
  let result = 0;

  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === 1) {
      count++;
      result = Math.max(result, count);
    } else {
      count = 0;
    }
  }

  return result;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — one pass.
2. **Space Complexity: O(1)** — two counters.
3. **Naive approach**: from every 1, extend forward counting 1s — O(n²) in the worst case (all 1s).

## *Key Points to Remember*
1. **Reset on 0, not on anything-else**: this only works for binary input; for general arrays you would compare with the target value instead.
2. **Update the answer while streaking**, so a streak ending at the array's end is still counted.
3. **This is a tiny sliding window**: the "window" grows on 1 and collapses on 0.

# **Conclusion**
Maximum consecutive 1s is a single scan with a streak counter that resets on 0: O(n) time and O(1) space. It is the simplest example of the streak/window pattern reused in Kadane's and even-odd subarray problems.
