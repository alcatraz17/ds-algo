# **Frequencies in a Sorted Array**

## *Introduction*
Given a **sorted** array, print each distinct value with the number of times it appears. Example: `[10, 10, 10, 25, 30, 30]` gives `10 → 3, 25 → 1, 30 → 2`. Because equal values are adjacent, we can count runs in one pass without any hash map.

## *Idea*
1. **Start a counter at 1** for the first element.
2. **Scan from index 1**: while the element equals the previous one, increment the counter.
3. **When the value changes**, record the previous value with its count and reset the counter to 1.
4. **After the loop**, record the final run — the last value's count is still pending.

### Code

```JavaScript
function printFrequencies(arr) {
  let count = 1;

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] === arr[i - 1]) {
      count++;
    } else {
      console.log(arr[i - 1], count);
      count = 1;
    }
  }

  console.log(arr[arr.length - 1], count);  // last run
}
```

## *Analysis*
1. **Time Complexity: O(n)** — one pass over the array.
2. **Space Complexity: O(1)** — only a counter.
3. **Unsorted arrays**: this trick fails; you need a `Map` like in `problems/10.numberFrequency.js`, which counts occurrences of two given values with O(n) time and O(1) extra space (only two keys stored).

## *Key Points to Remember*
1. **Do not forget the last group** — it is flushed after the loop, a very common off-by-one mistake.
2. **Single-element and empty arrays** need care: check `arr.length` before touching `arr[0]`.
3. **Sortedness is what makes O(1) space possible** — duplicates are guaranteed to be contiguous.

# **Conclusion**
Counting frequencies in a sorted array is a single scan that counts runs of equal values, printing each when the value changes: O(n) time and O(1) space. Remember to print the final run after the loop ends.
