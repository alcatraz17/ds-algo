# **Majority Element (Moore's Voting Algorithm)**

## *Introduction*
A majority element appears **more than n/2 times** in an array of size n. Example: in `[8, 3, 8, 8, 3, 8]` the answer is `8` (appears 4 times out of 6). Moore's voting algorithm finds the candidate in O(n) time and O(1) space.

## *Idea*
1. **Phase 1 — find a candidate**: keep a `candidate` and a `count`. Scan the array: if `count` is 0, take the current element as candidate. If the element matches the candidate, increment `count`; else decrement it.
2. **Intuition**: each majority element "cancels" one non-majority element, and since the majority is more than half, it survives all cancellations.
3. **Phase 2 — verify**: count the candidate's occurrences and confirm it is more than n/2. Moore's only *proposes* a candidate; it does not prove majority exists.

### Code

```JavaScript
function majorityElement(arr) {
  let candidate = -1;
  let count = 0;

  for (const num of arr) {              // phase 1
    if (count === 0) {
      candidate = num;
      count = 1;
    } else {
      count += (num === candidate) ? 1 : -1;
    }
  }

  count = 0;                            // phase 2: verify
  for (const num of arr) {
    if (num === candidate) count++;
  }

  return count > arr.length / 2 ? candidate : -1;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — two linear passes.
2. **Space Complexity: O(1)** — constant extra variables.
3. **Alternatives**: hash-map counting is O(n) time but O(n) space; sorting then checking the middle is O(n log n).

## *Key Points to Remember*
1. **Always verify** — if no majority exists (e.g. `[1, 2, 3]`), phase 1 still returns some element.
2. **Strictly more than n/2**, so at most one majority element can exist.
3. **Generalization**: the "appears more than n/k times" version keeps k−1 candidates.

# **Conclusion**
Moore's voting finds a majority candidate by pairing off differing elements, then verifies it with a second count: O(n) time, O(1) space. Never skip the verification pass — a candidate is not proof of majority.
