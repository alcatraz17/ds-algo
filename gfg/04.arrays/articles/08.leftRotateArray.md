# **Left Rotate an Array (by One and by D Places)**

## *Introduction*
Left rotation shifts every element to the left, and the elements that fall off the front wrap around to the back. Rotating `[1, 2, 3, 4]` by one gives `[2, 3, 4, 1]`.

## *Rotate by One*
1. **Save the first element** in a temp variable.
2. **Shift every element one step left.**
3. **Put the saved element at the end.**

### Code (from 07.leftRotate.js)

```JavaScript
leftRotate(arr) {
  let temp = arr[0];

  for (let i = 1; i < arr.length; i++) {
    arr[i - 1] = arr[i];
  }

  arr[arr.length - 1] = temp;
  return arr;
}
```

Time: O(n), Space: O(1). Rotating by D by repeating this D times costs O(n·d) — too slow for large D.

## *Rotate by D — the Reversal Algorithm*
1. **Reverse the first D elements.**
2. **Reverse the remaining n − D elements.**
3. **Reverse the whole array.** The pieces land in rotated order.

Example: `[1,2,3,4,5]`, d = 2 → reverse first 2: `[2,1,3,4,5]` → reverse rest: `[2,1,5,4,3]` → reverse all: `[3,4,5,1,2]`.

### Code (from ../problems/11.rotateArr.js)

```JavaScript
function rotateArr(arr, d) {
  let n = arr.length;
  d = d % n;               // rotating by n is a no-op
  if (d === 0) return arr;

  reverse(arr, 0, d - 1);
  reverse(arr, d, n - 1);
  reverse(arr, 0, n - 1);

  function reverse(arr, start, end) {
    while (start < end) {
      [arr[start], arr[end]] = [arr[end], arr[start]];
      start++;
      end--;
    }
  }
}
```

## *Analysis*
1. **Time Complexity: O(n)** — three reversals, each linear.
2. **Space Complexity: O(1)** — in-place, no temp array.
3. **Simpler alternatives**: using a temp array of the first D elements is O(n) time but O(d) space; juggling with a copy is O(n) space. Reversal is the best in-place method.

## *Key Points to Remember*
1. **Always reduce `d = d % n` first** — rotating by n brings the array back to itself (see the `d = 9` example in the problem file).
2. **The same `reverse` helper** from note 5 is reused here.
3. **Right rotation by D** is the same idea with the split flipped: reverse whole array, then reverse first D, then the rest.

# **Conclusion**
Rotating by one is a single O(n) shift. Rotating by D efficiently uses the reversal algorithm — three reversals, O(n) time, O(1) space — making it the standard interview answer for in-place rotation.
