# **Maximum Subarray Sum (Kadane's Algorithm)**

## *Introduction*
Find the contiguous subarray with the largest possible sum. Example: in `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` the answer is `6` from `[4, -1, 2, 1]`. Kadane's algorithm solves it in one pass.

## *Idea*
1. **Keep `maxEnding`**: the best sum of a subarray that ends at the current position.
2. **At each element, choose**: either extend the previous subarray (`maxEnding + arr[i]`) or start fresh at `arr[i]` — whichever is bigger.
3. **Track the overall best** seen so far and return it.

### Code

```JavaScript
function maxSubarraySum(arr) {
  let maxEnding = arr[0];
  let result = arr[0];

  for (let i = 1; i < arr.length; i++) {
    maxEnding = Math.max(maxEnding + arr[i], arr[i]);
    result = Math.max(result, maxEnding);
  }

  return result;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — single traversal.
2. **Space Complexity: O(1)** — two variables.
3. **Naive approach**: sum every possible subarray with nested loops — O(n²). A brute-force with three loops is O(n³).

## *Key Points to Remember*
1. **Handles all-negative arrays correctly**: initialize with `arr[0]`, not 0, so `[-5, -2, -3]` returns `-2`.
2. **Core intuition**: if the running sum becomes worse than starting fresh, the old prefix is a burden — drop it.
3. **To also recover the subarray indices**, track start/end positions whenever `result` is updated or a fresh start is made.
4. **Kadane's is the backbone** of the circular-subarray and even-odd subarray problems (notes 16 and 17).

# **Conclusion**
Kadane's algorithm finds the maximum subarray sum in O(n) time and O(1) space by deciding at each position whether to extend the running subarray or restart. It is one of the most important array patterns to know.
