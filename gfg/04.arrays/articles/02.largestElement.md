# **Largest Element in an Array**

## *Introduction*
The task is simple: given an array, find the biggest value in it. Since the elements are in no particular order, we have no choice but to look at every element at least once.

## *Idea*
1. **Assume the first element is the largest** and store it in a variable.
2. **Scan the rest of the array**: whenever you find a bigger value, update the variable.
3. **Return the variable** after the loop ends.

### Code (from 01.largestNumber.js)

```JavaScript
function arrayMax(arr) {
  let arrMax = arr[0];

  for (let i = 1; i <= arr.length - 1; i++) {
    if (arr[i] > arrMax) arrMax = arr[i];
  }

  return arrMax;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — one pass through the array.
2. **Space Complexity: O(1)** — only one extra variable is used.
3. **Cannot do better**: every element must be checked at least once, so O(n) is optimal.

## *Key Points to Remember*
1. **Initialize with the first element**, not with 0 — initializing with 0 breaks on arrays of negative numbers.
2. **Built-in alternative**: `Math.max(...arr)` works, but spreads can fail on very large arrays; the loop is the safe interview answer.
3. **This pattern repeats**: "track a best-so-far value in one pass" shows up in second largest, max difference, Kadane's and many other problems.

# **Conclusion**
Finding the largest element is a single linear scan: start with the first element and keep the biggest value seen so far. It runs in O(n) time and O(1) space, which is the best possible since every element must be inspected.
