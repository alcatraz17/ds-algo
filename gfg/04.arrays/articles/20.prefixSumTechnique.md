# **Prefix Sum Technique**

## *Introduction*
A prefix sum array `pre` stores at index i the sum of all elements up to i: `pre[i] = arr[0] + arr[1] + ... + arr[i]`. After one O(n) preprocessing pass, the sum of **any range** [l, r] can be answered in O(1): `pre[r] − pre[l − 1]`.

## *Idea*
1. **Build the prefix array**: `pre[0] = arr[0]`, then `pre[i] = pre[i − 1] + arr[i]`.
2. **Range sum query** [l, r]: return `pre[r] − (l > 0 ? pre[l − 1] : 0)`.

### Code

```JavaScript
function buildPrefix(arr) {
  const pre = [arr[0]];
  for (let i = 1; i < arr.length; i++) {
    pre[i] = pre[i - 1] + arr[i];
  }
  return pre;
}

function rangeSum(pre, l, r) {
  return l === 0 ? pre[r] : pre[r] - pre[l - 1];
}
```

## *Analysis*
1. **Build time: O(n)** — one pass.
2. **Query time: O(1)** per range-sum query — versus O(n) if you summed the range directly each time.
3. **Space Complexity: O(n)** for the prefix array.

## *Key Applications*
1. **Many range-sum queries**: the main use case — preprocess once, answer instantly.
2. **Check if an equilibrium index exists**: an index where the left sum equals the right sum — compare `pre[i − 1]` with `pre[n − 1] − pre[i]`.
3. **Subarray with a given sum** (with negatives): use prefix sums plus a hash map — if `pre[j] − pre[i]` equals the target, a matching subarray exists. O(n) time, O(n) space.
4. **2D extension**: prefix sums over a matrix answer rectangle sums in O(1).

## *Key Points to Remember*
1. **Prefix sums trade space for time**: O(n) extra space converts O(n) per query into O(1).
2. **Off-by-one danger**: `rangeSum(l, r) = pre[r] − pre[l − 1]` — handle `l === 0` separately.
3. **Related technique**: a suffix/left-max array (as in trapping rain water, note 13, and `../problems/03.maxIndexDiff.js`) is the same "precompute running aggregates" idea with max instead of sum.

# **Conclusion**
Prefix sums preprocess an array in O(n) so that any range-sum query takes O(1). The pattern generalizes to equilibrium checks, subarray-sum problems with a hash map, and running max/min arrays used in many array problems.
