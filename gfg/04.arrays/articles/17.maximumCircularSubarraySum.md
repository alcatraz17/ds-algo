# **Maximum Circular Subarray Sum**

## *Introduction*
Same goal as the maximum subarray problem, but the array is treated as a **circle** — the subarray may wrap around from the end to the beginning. Example: `[5, -2, 3, 4]` gives `12` from the wrapping subarray `[3, 4, 5]`.

## *Idea (Two Cases)*
1. **Case 1 — no wrapping**: the answer is just the normal Kadane's maximum subarray sum.
2. **Case 2 — wrapping**: a wrapping max subarray is the whole array minus the *minimum* subarray in the middle. So compute `totalSum − minSubarraySum` (minimum via Kadane's on negated values, or by flipping the comparisons).
3. **Answer** = `max(normalKadane, totalSum − minKadane)`.

### Code

```JavaScript
function maxCircularSum(arr) {
  const kadane = (a) => {
    let maxEnding = a[0], best = a[0];
    for (let i = 1; i < a.length; i++) {
      maxEnding = Math.max(maxEnding + a[i], a[i]);
      best = Math.max(best, maxEnding);
    }
    return best;
  };

  const maxNormal = kadane(arr);
  if (maxNormal < 0) return maxNormal;   // all negative: no wrap allowed

  let total = 0;
  for (let i = 0; i < arr.length; i++) {
    total += arr[i];
    arr[i] = -arr[i];                    // invert to get min subarray
  }

  const maxWrap = total + kadane(arr);   // total − (min subarray sum)
  return Math.max(maxNormal, maxWrap);
}
```

## *Analysis*
1. **Time Complexity: O(n)** — Kadane's runs twice.
2. **Space Complexity: O(1)** — in-place inversion.
3. **Naive approach**: try every circular subarray — O(n²).

## *Key Points to Remember*
1. **All-negative edge case**: `totalSum − minSubarray` becomes 0 (empty subarray), which is invalid — so return the plain Kadane's answer when it is negative.
2. **The trick**: maximizing the wrapped sum is the same as minimizing the non-wrapped middle.
3. **Reuses note 15** — if you know Kadane's, this is one extra insight.

# **Conclusion**
Maximum circular subarray sum is Kadane's run twice: once normally, and once via `totalSum − minSubarraySum` for the wrapping case, with an all-negative guard. It stays O(n) time and O(1) space.
