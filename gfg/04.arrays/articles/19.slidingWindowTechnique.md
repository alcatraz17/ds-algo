# **Sliding Window Technique**

## *Introduction*
The sliding window technique answers questions about **contiguous subarrays (or substrings) of fixed or varying size** without re-scanning elements. Instead of recomputing from scratch for each window, you update the previous window's result by removing the element that left and adding the element that entered.

## *Fixed-Size Window: Maximum Sum of K Consecutive Elements*
1. **Compute the sum of the first k elements** — the first window.
2. **Slide the window one step**: subtract the element going out (index `i − k`) and add the element coming in (index `i`).
3. **Track the maximum** window sum.

### Code

```JavaScript
function maxSumK(arr, k) {
  if (arr.length < k) return -1;

  let windowSum = 0;
  for (let i = 0; i < k; i++) windowSum += arr[i];

  let maxSum = windowSum;
  for (let i = k; i < arr.length; i++) {
    windowSum += arr[i] - arr[i - k];
    maxSum = Math.max(maxSum, windowSum);
  }

  return maxSum;
}
```

## *Variable-Size Window*
For problems like "smallest subarray with sum ≥ target" (positive numbers): grow the window from the right until the condition holds, then shrink from the left while it still holds, recording the best answer.

## *Analysis*
1. **Time Complexity: O(n)** — each element enters and leaves the window once.
2. **Space Complexity: O(1)** — only a few counters.
3. **Naive approach**: recompute every window — O(n·k).

## *Key Points to Remember*
1. **Fixed window**: one add, one remove per step.
2. **Variable window**: two pointers (`start`, `end`) that only move forward — that monotonicity is what keeps it O(n).
3. **Classic uses**: max sum of size k, longest substring without repeating characters, count subarrays with a given sum (with positives).

# **Conclusion**
Sliding window turns O(n·k) brute force into O(n) by reusing the previous window's result: add the new element, remove the old one. It is the go-to pattern for contiguous subarray and substring problems.
