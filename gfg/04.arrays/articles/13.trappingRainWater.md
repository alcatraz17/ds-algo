# **Trapping Rain Water**

## *Introduction*
Given an array of bar heights representing an elevation map, compute how much water is trapped between the bars after rain. Water above a bar depends on the **tallest bar to its left** and the **tallest bar to its right**: water at position i = `min(maxLeft, maxRight) − arr[i]`.

## *Idea (Precompute Left and Right Maxima)*
1. **Build `leftMax[i]`**: the tallest bar from the start up to i.
2. **Build `rightMax[i]`**: the tallest bar from the end down to i.
3. **Sum** `min(leftMax[i], rightMax[i]) − arr[i]` over all positions (only positive values count).

### Code

```JavaScript
function trapWater(arr) {
  const n = arr.length;
  if (n < 3) return 0;

  const leftMax = new Array(n);
  const rightMax = new Array(n);

  leftMax[0] = arr[0];
  for (let i = 1; i < n; i++) {
    leftMax[i] = Math.max(leftMax[i - 1], arr[i]);
  }

  rightMax[n - 1] = arr[n - 1];
  for (let i = n - 2; i >= 0; i--) {
    rightMax[i] = Math.max(rightMax[i + 1], arr[i]);
  }

  let water = 0;
  for (let i = 0; i < n; i++) {
    water += Math.min(leftMax[i], rightMax[i]) - arr[i];
  }

  return water;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — three linear passes.
2. **Space Complexity: O(n)** — two helper arrays.
3. **Two-pointer optimization**: keep `lMax`/`rMax` variables and move the pointer on the side with the smaller max — O(n) time, **O(1) space**.
4. **Naive approach**: for each bar scan left and right for maxima — O(n²).

## *Key Points to Remember*
1. **The first and last bars never trap water** — nothing beyond them to hold it.
2. **The precompute pattern** (left max / right max arrays) is the same idea used in `../problems/03.maxIndexDiff.js` with left-minimum and right-maximum arrays — worth recognizing.
3. **Formula intuition**: a bar holds water only up to the *lower* of its two surrounding walls.

# **Conclusion**
Trapping rain water reduces to `min(leftMax, rightMax) − height` per position. Precomputing the maxima gives O(n) time with O(n) space, and a two-pointer walk reduces the space to O(1). The naive O(n²) version is only useful for explaining the idea.
