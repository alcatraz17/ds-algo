# **Reverse an Array**

## *Introduction*
Reversing means the first element becomes the last, the second becomes the second-last, and so on. The classic in-place method uses two pointers moving toward each other.

## *Idea (Two Pointers)*
1. **Place one pointer at the start** and one at the end.
2. **Swap the two elements**, then move the pointers one step toward each other.
3. **Stop when the pointers meet or cross** — every pair has been swapped.

### Code (from 04.reverseAnArray.js)

```JavaScript
function reverseArray(arr) {
  let start = 0,
    end = arr.length - 1;

  while (start < end) {
    [arr[start], arr[end]] = [arr[end], arr[start]];
    start++;
    end--;
  }

  return arr;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — n/2 swaps, which is linear.
2. **Space Complexity: O(1)** — in-place; no extra array needed.
3. **Naive alternative**: copying elements into a new array in reverse order costs O(n) extra space.

## *Key Points to Remember*
1. **Destructuring swap** `[a, b] = [b, a]` is a clean JavaScript way to swap without a temp variable.
2. **Condition is `start < end`**, not `<=` — swapping the middle element with itself is harmless but useless.
3. **This helper is reused everywhere**: the reversal algorithm for rotation (`../problems/11.rotateArr.js`) and reversing in groups (`../problems/07.reverseArrayInGroups.js`) are both built on this exact swap loop.

# **Conclusion**
Reversing an array in place takes two pointers, n/2 swaps, O(n) time and O(1) space. Master this small loop — it is the core ingredient of the array rotation reversal algorithm.
