# **Longest Even-Odd Subarray**

## *Introduction*
Find the longest contiguous subarray where elements strictly alternate between even and odd. Example: in `[10, 12, 14, 7, 8]` the subarray `[14, 7, 8]` has length 3 (even → odd → even).

## *Idea (Kadane's-Style Streak)*
1. **Track the current streak length** of alternating parity ending at the current position.
2. **At each index i**: if `arr[i]` and `arr[i − 1]` have different parity (one even, one odd), extend the streak; otherwise reset it to 1.
3. **Keep the maximum streak** seen.

### Code

```JavaScript
function longestEvenOdd(arr) {
  let curr = 1;
  let result = 1;

  for (let i = 1; i < arr.length; i++) {
    if ((arr[i] % 2 === 0 && arr[i - 1] % 2 === 1) ||
        (arr[i] % 2 === 1 && arr[i - 1] % 2 === 0)) {
      curr++;
      result = Math.max(result, curr);
    } else {
      curr = 1;
    }
  }

  return result;
}
```

## *Analysis*
1. **Time Complexity: O(n)** — single pass.
2. **Space Complexity: O(1)** — two counters.
3. **Naive approach**: check every subarray for the alternating property — O(n²).

## *Key Points to Remember*
1. **Only parity matters**, not values — think of the array as a sequence of E's and O's.
2. **Same shape as maximum consecutive 1s** (note 14): grow the streak while a condition holds, reset when it breaks.
3. **Single-element array** has answer 1 by default.
4. **Kadane's connection**: like Kadane's, you maintain "best ending here" and "best overall".

# **Conclusion**
The longest even-odd subarray is found in one O(n) pass with O(1) space by growing a streak while adjacent elements alternate in parity and resetting when they do not. It follows the same streak pattern as the consecutive-1s problem.
