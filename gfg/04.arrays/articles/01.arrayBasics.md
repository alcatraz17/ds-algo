# **Array Basics in JavaScript**

## *Introduction*
An array is a collection of elements stored at contiguous positions and accessed using an index starting from 0. In JavaScript, arrays are actually dynamic objects under the hood — they can grow, shrink, and even hold mixed types — but they behave like classic arrays for learning purposes.

### Declaring Arrays

```JavaScript
let arr1 = [];                    // empty array (preferred)
let arr2 = [1, 2, 3, 4];          // array with values
let arr3 = new Array(5);          // array with 5 empty slots
arr2.push(5);                     // add at end
console.log(arr2.length);         // number of elements
```

## *Key Operations and Their Cost*
1. **Access by index**: Reading `arr[i]` is O(1) — you jump straight to the position.
2. **Insert at end**: `arr.push(x)` is O(1) on average. See `../problems/02.insertAtEnd.js` which does `arr[arr.length] = ele`.
3. **Insert at an index**: You must shift every element after that index one step right — O(n). See `../problems/01.insertAtIndex.js`.
4. **Delete from an index**: You must shift every element after it one step left — O(n).
5. **Searching**:
   - **Unsorted array**: linear search, check each element — O(n).
   - **Sorted array**: binary search, halve the range each step — O(log n).

### Insert at an Index (from ../problems/01.insertAtIndex.js)

```JavaScript
function insertAtIndex(arr, val, index) {
  for (let i = arr.length; i > index; i--) {
    arr[i] = arr[i - 1];      // shift elements right
  }
  arr[index] = val;
  return arr;
}
```

## *Key Points to Remember*
1. **Indexing starts at 0**: the last element is at `arr.length - 1`.
2. **Fast access, slow insert/delete in the middle**: this trade-off is the core of array-based problems.
3. **JS arrays are dynamic**: unlike fixed-size arrays in C/Java, `length` grows automatically.

# **Conclusion**
Arrays give constant-time access by index but linear-time insertion and deletion in the middle because of shifting. Searching is O(n) by linear search and O(log n) by binary search on sorted arrays. Knowing these costs helps decide when an array is the right data structure.
