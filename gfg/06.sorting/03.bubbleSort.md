# **Bubble Sort**

## *Introduction*
Bubble sort is the simplest comparison-based sorting algorithm. It repeatedly steps through the array, compares **adjacent elements** and swaps them if they are in the wrong order. After each pass, the largest element "bubbles up" to its correct position at the end.

### How It Works
1. Compare `arr[j]` and `arr[j + 1]`, swap if out of order.
2. After pass 1, the largest element is at the last index — so the inner loop can shrink by 1 each pass (`length - 1 - i`).
3. Repeat until no swaps are needed.

### Swapped-Flag Optimization
If a complete pass makes **no swaps**, the array is already sorted and we can stop early. This is done with a `swapped` flag — see `articles/02.bubbleSort.js`:

```javascript
function bubbleSort(arr) {
  let length = arr.length;
  let swapped = false;

  for (let i = 0; i < length; i++) {
    swapped = false;
    for (let j = 0; j < length - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
        swapped = true;
      }
    }
    if (swapped === false) break; // already sorted
  }
  return arr;
}
```

### Complexity
1. **Time (worst/avg)**: O(n²) — nested loops over the array.
2. **Time (best)**: O(n) — with the swapped flag, one pass is enough for an already sorted array.
3. **Space**: O(1) — sorts in place.
4. **Stable**: Yes — equal elements are never swapped past each other.

### Key Points to Remember
1. Good for learning and for very small or nearly sorted arrays.
2. Too slow for large inputs — never used in practice for real data.
3. The swapped-flag turns the best case into linear time.

# **Conclusion**
Bubble sort compares and swaps adjacent elements, pushing the largest value to the end on each pass. With the swapped-flag optimization it detects a sorted array early (O(n) best case), but its O(n²) average time makes it unsuitable for large datasets.
