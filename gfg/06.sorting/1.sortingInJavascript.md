# **Sorting in JavaScript**

## *Introduction*
Sorting means arranging elements of a collection in a particular order, usually ascending or descending. JavaScript has a built-in method for this: `Array.prototype.sort()`. It sorts the array **in place** (the original array is changed) and returns the same array.

### Default Behavior (Important!)
1. **Sorts as strings**: By default, `sort()` converts every element to a string and compares them by UTF-16 code units.
2. **Numbers get sorted wrong**: Because of string comparison, `10` comes before `9` (`"10"` < `"9"` in dictionary order).

```javascript
let arr = [100, 9, 25, 3];
arr.sort();
console.log(arr); // [100, 25, 3, 9] — NOT numerically sorted!
```

### Using a Comparator Function
To control the order, pass a compare function `compare(a, b)`:

1. If it returns a **negative** value → `a` comes **before** `b`.
2. If it returns a **positive** value → `b` comes **before** `a`.
3. If it returns **0** → order of `a` and `b` stays unchanged.

```javascript
// Ascending order for numbers
arr.sort((a, b) => a - b);
console.log(arr); // [3, 9, 25, 100]

// Descending order for numbers
arr.sort((a, b) => b - a);
console.log(arr); // [100, 25, 9, 3]
```

### Sorting Strings
Strings are sorted alphabetically by default (uppercase letters come before lowercase). For case-insensitive sorting:

```javascript
let names = ["banana", "Apple", "cherry"];
names.sort((a, b) => a.toLowerCase().localeCompare(b.toLowerCase()));
// ["Apple", "banana", "cherry"]
```

### Key Points to Remember
1. `sort()` modifies the original array — use `[...arr].sort()` if you need a copy.
2. Always pass a comparator when sorting **numbers**.
3. Time complexity of the built-in sort is generally **O(n log n)** (V8 uses TimSort), and it is **stable** in modern JavaScript engines.

# **Conclusion**
JavaScript's built-in `sort()` is powerful but tricky: by default it compares elements as strings. For numbers always provide a comparator like `(a, b) => a - b`, and remember it sorts in place at O(n log n) time.
