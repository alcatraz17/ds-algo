# **Insertion Sort**

## *Introduction*
Insertion sort builds the sorted array one element at a time, just like sorting a hand of playing cards. It takes the next element (the **key**) and shifts all larger elements one position to the right until it finds the correct spot to insert the key.

### How It Works
1. Start from the second element (index 1); everything to the left is treated as sorted.
2. Store the current element as `key`.
3. Shift elements greater than `key` one step right.
4. Place `key` in the gap that opens up.

See `articles/01.insertionSort.js` and `articles/04.insertionSort.js`:

```javascript
function insertionSort(arr) {
  for (let i = 0; i < arr.length; i++) {
    let key = arr[i];
    let j = i - 1;

    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j]; // shift right
      j--;
    }
    arr[j + 1] = key; // insert key in its place
  }
  return arr;
}
```

### Complexity
1. **Time (best)**: O(n) — when the array is already sorted, the inner while loop never runs.
2. **Time (avg/worst)**: O(n²) — worst case is a reverse-sorted array.
3. **Space**: O(1) — in place.
4. **Stable**: Yes — equal elements are never moved past each other.

### Key Points to Remember
1. Excellent for **nearly sorted** arrays — approaches O(n).
2. Fast in practice for small arrays; TimSort (used by V8) uses insertion sort for small chunks.
3. Adaptive and online: it can sort a stream of elements as they arrive.

# **Conclusion**
Insertion sort inserts each element into its correct place within the already-sorted left part. It runs in O(n²) worst case but O(n) on nearly sorted data, is stable, in place, and is the best simple sort for small or almost-sorted arrays.
