# **Selection Sort**

## *Introduction*
Selection sort divides the array into a **sorted part** (left) and an **unsorted part** (right). On every pass it finds the **minimum element** in the unsorted part and swaps it into the next position of the sorted part.

### How It Works
1. Find the index of the minimum element in the unsorted region.
2. Swap it with the first element of the unsorted region.
3. Grow the sorted region by one and repeat.

See `03.selectionSort.js`:

```javascript
function selectionSort(arr) {
  let length = arr.length;

  for (let i = 1; i < length; i++) {
    let minInd = i;
    for (let j = i + 1; j < length; j++) {
      if (arr[j] < arr[minInd]) {
        minInd = j;
      }
    }
    [arr[minInd], arr[i]] = [arr[i], arr[minInd]];
  }
  return arr;
}
```

### Complexity
1. **Time**: O(n²) in best, average and worst case — the inner scan always runs fully.
2. **Space**: O(1) — in place.
3. **Stable**: **No** — a swap can jump an equal element past another one.
4. **Swaps**: At most O(n) swaps — fewer writes than bubble sort, which can matter when writes are expensive.

### Key Points to Remember
1. Selection sort does the **minimum number of swaps** (at most n − 1) among the simple sorts.
2. It never benefits from an already sorted input — always O(n²).
3. It is not stable, unlike bubble and insertion sort.

# **Conclusion**
Selection sort repeatedly picks the smallest remaining element and places it in its final spot. It always runs in O(n²) time and O(1) space, makes very few swaps, but is not stable and is only suitable for small arrays.
